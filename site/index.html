Before you download

A few things to know.

How ready is this preview?

The Windows interface, local discovery, runtime setup, and generated-video decoding/display have been checked. Physical-iPhone mirroring can be intermittent; reliable reconnection, audio synchronization, and device compatibility still need further device checks. This is an unsigned preview, not a certified app-store release.

See the open device checklist
What stays on my computer?

The app keeps preferences and receiver files locally. Mirroring is designed for your local network, not a cloud relay. This website demo never sends your sample note anywhere. It does not access a real device.

Do I need another app on my iPhone?

No companion iPhone app is required. MirrorMe receives AirPlay screen mirroring through UxPlay. The one-time PC download supplies the media and discovery libraries; the separate UxPlay desktop app is not installed or opened.

Can I mirror everything?

Protected streaming content may block screen mirroring. MirrorMe is a receiver, not remote control of your iPhone. Windows 11 on an x64 PC is the preview target; ARM and every iPhone/iOS combination have not been validated.

Why might Windows show a warning?

The preview is not code-signed. Check the public source and the release's SHA-256 checksums before deciding whether to run it. Do not disable Windows security protections to use this app.

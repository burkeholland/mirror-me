Shared native build inputs
=========================

This directory no longer contains an external receiver implementation.
The application uses only the self-contained host in native/.

The native build still uses these inputs:
- resources/mirrorme.ico: generated from site/assets/mark.svg.
- tests/blue-frame.h264: original generated video test fixture.
- vendor/libuxplay: ignored, pristine checkout of the protocol source pinned
  in native/dependencies.json. scripts/build-app.ps1 restores it.

Do not remove upstream protocol copyrights or license notices. This is
licensed compatibility code, not a clean-room AirPlay implementation.
See THIRD-PARTY-NOTICES.md and native/NATIVE-SOURCE-NOTICES.txt.
